# GranCarb
Description: Attempt at a modern recreation of Carbdose application used by the EPA to aid with Radon mitigation in the 1990s. Will use WxPython to match, as closely as possible, the original layout of the Carbdose program.

Antivirus Flags: Doing this in python using Pyinstaller to generate an executable means that the resulting executable file is lacking a "paid commercial code-signing certificate". Windows Defender and corporate antivirus scanners may flag it as a false positive. The code base is entirely open source for review.
